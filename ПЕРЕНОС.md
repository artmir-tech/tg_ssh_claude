# Перенос Claude Control на другой аккаунт этого сервера

У второго пользователя сервера (например, `dev`) появится **своя** такая же система: свой бот,
своя группа в Telegram, свои сессии Claude Code под **его** входом в Claude. С исходной системой
она никак не связана: ни токенов, ни базы, ни сессий из неё не переносится — только готовый код,
который берётся с GitHub: https://github.com/artmir-tech/tg_ssh_claude

Два важных правила:
- **Нужен отдельный бот.** Один токен бота может обслуживать только одну систему.
- **Память сервера общая.** Каждая задача Claude занимает ~300–400 МБ. Для второй системы ставим
  не больше 3 задач одновременно (`MAX_CONCURRENT_RUNS=3`).

---

## Шаги 1–5. Telegram (делает владелец второго аккаунта, с телефона)

**ШАГ 1.** Откройте Telegram → найдите **@BotFather** → напишите `/newbot`.
Придумайте имя (например, `Claude Dev`) и username, который заканчивается на `bot`
(например, `claude_dev_control_bot`). BotFather пришлёт строку-**token** — скопируйте её.

**ШАГ 2.** Чаты → ✏️ → **Создать группу** → найдите своего нового бота → **Далее** →
название группы (например, `Claude Control Dev`) → **Создать**.

**ШАГ 3.** Откройте группу → нажмите на название вверху → **Изм.** → включите **Темы** → **Готово**.

**ШАГ 4.** Там же: **Изм.** → **Администраторы** → **Добавить администратора** → ваш бот →
включите **«Управление темами»**, **«Удаление сообщений»**, **«Закрепление сообщений»** → **Готово**.

**ШАГ 5.** В теме **General** напишите: `/start`

## Шаг 6. Claude Code во втором аккаунте

Подключитесь к серверу в VS Code **под вторым аккаунтом** и откройте Claude Code.
Он должен быть уже залогинен (это обычная работа в VS Code). Вставьте в чат текст ниже,
заменив `ВСТАВЬТЕ_ТОКЕН` на token из шага 1:

```text
Разверни готовую систему Claude Control (Telegram-пульт для сессий Claude Code) для моего пользователя.
Её уже написали и проверили под другим пользователем этого сервера. Не пиши её заново и не меняй код.

1. Склонируй: git clone https://github.com/artmir-tech/tg_ssh_claude.git ~/claude-control
   Прочитай ~/claude-control/README.md, ~/claude-control/CLAUDE.md и ~/claude-control/ПЕРЕНОС.md.
2. Проверь, что мой Claude Code залогинен: claude auth status. Если нет — скажи мне, что сделать.
3. Токен моего бота: ВСТАВЬТЕ_ТОКЕН
   Создай ~/claude-control/.env из .env.example (chmod 600). Токен нигде не выводи и не логируй.
4. Я уже создал группу с темами, сделал бота администратором и написал /start в General.
   Сервис ещё не запущен — узнай ID группы и мой Telegram ID: python3 ~/claude-control/deploy/find_ids.py
   Покажи мне найденные имя и username, я подтвержу, что это я. Запиши их в OWNER_IDS и TELEGRAM_CHAT_ID.
5. Настройки в .env: MAX_CONCURRENT_RUNS=3 (на сервере уже работает вторая такая система, память общая),
   DEFAULT_CWD и PROJECT_DIRS — моя домашняя папка и мои рабочие папки, TIMEZONE=Asia/Tbilisi.
6. Установи: bash ~/claude-control/deploy/install.sh
   (зависимости, systemd-сервис, автозапуск после перезагрузки).
7. Проверь: systemctl --user status claude-control; journalctl --user -u claude-control -n 50;
   что токена в логах нет. Прогони короткие тесты из папки ~/claude-control:
   env -i HOME=$HOME PATH=/usr/bin:/bin LANG=C.UTF-8 .venv/bin/python -m tests.acceptance T1 T2 T8
8. Скажи мне, что проверить в Telegram.

Нельзя: --dangerously-skip-permissions, менять мой вход в Claude Code, заходить в чужие домашние папки.
```

Claude сделает всё сам и спросит только подтверждение, что найденный Telegram-аккаунт — ваш.

## Как обновлять потом

Когда систему улучшат и загрузят на GitHub, во втором аккаунте достаточно одной команды
(настройки `.env` и база `data/` не затрагиваются):

```bash
cd ~/claude-control && git pull && bash deploy/install.sh
```

Или попросите Claude Code в этом аккаунте: «обнови claude-control с GitHub».

## Если GitHub недоступен

В исходном аккаунте выполните `bash ~/claude-control/deploy/package.sh` — появится архив
`/tmp/claude-control.tar.gz` (без токена, базы и сессий), который может прочитать любой пользователь сервера.
Во втором аккаунте вместо `git clone`:

```bash
tar -xzf /tmp/claude-control.tar.gz -C ~
```
